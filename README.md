# Dev-Insight 🔍
### GitHub Profile Analyzer

A clean, visual dashboard that turns any GitHub username into a data-driven profile breakdown — languages used, stars, followers, and more.

> 🚧 **Status: In active development** — built as a learning project, evolving weekly.

---

## ✨ Features

- 🔎 Search any GitHub username
- 🪪 Profile identity card — avatar, name, bio, location, link to profile
- 📊 Quantitative stats grid — public repos, followers, following, total stars
- 🧠 Language breakdown — computed from real repo data (e.g. JavaScript 68%, HTML 22%)
- 🌗 Dark / Light mode toggle with persistence (localStorage)
- 📱 Fully responsive — desktop 3-column layout, mobile single-column

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript (fetch API, async/await)
- [GitHub REST API](https://docs.github.com/en/rest)

## 🚀 Getting Started (Run Locally)

If you want to download and run this project on your own machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation

1. **Clone the repository:**
   Open your terminal and run:
   ```bash
   git clone [https://github.com/Tanmayyee/github-profile-analyzer.git](https://github.com/Tanmayyee/github-profile-analyzer.git)

2. **Go to the project directory:**   
   cd OMDb-movie-finder

3. **Install the dependencies:**
   npm install

4. **Start the development server:**   
   npm run dev
